# Drift Rush

基于 Three.js、TypeScript、Vite 的电脑浏览器 3D 街机竞速原型。一辆原创赛车、一张约 1.06 km 的海岸环线，每场三圈。源代码托管于[公开 GitHub 仓库](https://github.com/leonsux/drift-rush)。

## 启动

使用 Node.js 24 与 npm。在项目目录执行：

```powershell
npm install
npm run dev
```

浏览器打开 <http://127.0.0.1:5173/>。点击「驶入赛道」或按 Enter，倒计时结束后驾驶。音效仅在用户操作之后启动。

```powershell
npm test          # 驾驶、碰撞、喷气及三圈路线测试
npm run build    # TypeScript 检查及 dist/ 生产构建
npm run preview  # 本地预览生产构建，端口 4173
```

## 操作

| 按键 | 功能 |
| --- | --- |
| W / ↑ | 持续加速 |
| S / ↓ | 刹车 |
| A、D / ←、→ | 左右转向 |
| Shift + 转向 | 达到一定速度后进入漂移 |
| Space | 有效漂移结束后的 1.8 秒内触发小喷 |
| E / Ctrl | 消耗一罐氮气，持续加速 2.8 秒 |
| Esc | 暂停或继续；切出窗口也会自动暂停 |
| R | 重开当前比赛 |

使用 WASD 时推荐 E 释放氮气，避免 Ctrl + W 浏览器快捷键。漂移时可反打修正；松开 Shift 恢复抓地力。初始提供一罐氮气，漂移继续集气，最多储存两罐。碰撞会损失速度，但可以继续驾驶。三个分段检查点通过后才能计圈，逆行穿越终点不能刷圈。

## 当前内容

- 程序化海岸场景、棕榈树、灯塔、海湾、帆船与赛道标识。
- 固定 120 Hz 驾驶模拟，独立渲染；车身侧滑、跟随镜头、拖痕、烟雾和喷焰。
- 引擎转速、换挡音高、轮胎摩擦、风噪、喷气、碰撞和倒计时合成音效，提供静音与音量控制。
- 圈数、计时、赛道小地图、氮气与小喷状态；结算显示每圈成绩。
- 最佳总成绩保存在当前浏览器本地；禁用存储时仍可游戏。
- 适配窗口尺寸，并在窄屏提示使用电脑键盘；本版不提供触屏驾驶。
- 支持的浏览器可通过 WebMCP 读取比赛状态、暂停及继续比赛；不支持时不影响游戏。

游戏不依赖在线模型、字体或音效资源。首次加载需要支持 WebGL 2 的浏览器与硬件加速。所有画面和音效都是当前原型实现，并非 QQ 飞车的官方素材或物理参数。

实现状态及验证限制见 [ROADMAP.md](ROADMAP.md)，工程约定见 [AGENTS.md](AGENTS.md)。
